### v1.5.5
`2026-08-29 07:45`

- **公告**：本项目从 [CF-Submissions-Ratings (CFSR)](https://github.com/GodExious/CF-Submissions-Ratings) v1.5.5 迁移并更名而来，作为 Colorforces 的初代 v1.5.5 版本。后续的所有功能开发与维护都将在此版本基础上继续进行。
- 新增：实时界面预览。当在设置菜单改变样式选择时，页面将实时反映展示效果。
- 优化：轻微美化了设置菜单的 UI，在底部增设了项目链接和快速反馈通道。
- 优化：将虚拟竞赛的开始时间也一并纳入了可选的时间格式化范围。

### v1.5.2
`2026-08-24 14:15`

- 修复：修复了在非数据表格（如 Recent Actions 动态页面）中，由于文本换行或表格布局误判导致头像被挤到上一行的问题。

### v1.5.1
`2026-08-24 01:39`

- 修复：彻底删除了在普通页面题目链接旁附加 `[xxxx]` 分数文本显示的冗余逻辑。
- 修复：修复了关闭自定义时间格式时，表格时间列排版错乱的问题，完全恢复官方默认样式。
- 新增：支持在设置面板中自由切换难度分呈现样式（经典“色块” / iView 风格“标签”）。
- 新增：支持在设置面板中通过开关控制难度分在不同区域（提交、状态、Hack、各大题单、榜单及题目页标签）的显示。
- 新增：支持开启并自定义时间格式化字符串，自带实时预览。
- 新增：支持在表格中显示用户头像，并在设置中支持自定义大小。
- 新增：支持在语言列显示语言专属图标（如 C++、Python、Go 等），并支持自定义图标大小。
- 新增：支持将判题状态进行极简缩写（如 `Accepted` -> `AC`, `Time limit exceeded` -> `TLE` 等）。
- 修复：修复了在使用深色背景插件（如 Dark Reader、CF-Better）时，难度分高亮背景刺眼的问题。
