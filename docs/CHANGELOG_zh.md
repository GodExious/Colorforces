### v1.5.6
`2026-09-01 03:10`

1. 优化：优化了部分 ICPC 区域赛榜单在开启“显示用户头像”和“队伍信息格式化”时，Ghost Participant 队伍名称与成员信息的排版样式。
2. 优化：升级了插件设置菜单 UI，引入分组导航（通用、界面、难度分、用户），使选项结构更加清晰易用。
3. 优化：在“难度分”设置中增加了“色彩展示难度分”总开关，支持一键开启或关闭全站难度分着色与展示。
4. 新增：新增了“隐藏算法标签”功能，支持隐藏题目页右侧具体的算法 Tag，仅保留难度评分。

### v1.5.5
`2026-08-29 07:45`

3. 优化：将虚拟竞赛的开始时间也一并纳入了可选的时间格式化范围。
4. 新增：实时界面预览。当在设置菜单改变样式选择时，页面将实时反映展示效果。

### v1.5.1
`2026-08-24 01:39`

1. 修复：彻底删除了在普通页面题目链接旁附加 `[xxxx]` 分数文本显示的冗余逻辑。
2. 修复：修复了关闭自定义时间格式时，表格时间列排版错乱的问题，完全恢复官方默认样式。
3. 修复：修复了在使用深色背景插件（如 Dark Reader、CF-Better）时，难度分高亮背景刺眼的问题。
4. 新增：支持在设置面板中自由切换难度分呈现样式（经典“色块” / iView 风格“标签”）。
5. 新增：支持在设置面板中通过开关控制难度分在不同区域（提交、状态、Hack、各大题单、榜单及题目页标签）的显示。
6. 新增：支持开启并自定义时间格式化字符串，自带实时预览。
7. 新增：支持在表格中显示用户头像，并在设置中支持自定义大小。
8. 新增：支持在语言列显示语言专属图标（如 C++、Python、Go 等），并支持自定义图标大小。
9. 新增：支持将判题状态进行极简缩写（如 `Accepted` -> `AC`, `Time limit exceeded` -> `TLE` 等）。
