### v1.5.7
`2026-09-08 03:45`

**新增**
1. 接入第三方 [CList](https://clist.by) 题目数据源，支持展示更加精细的题目难度评分，并提供 Cookie 会话与 API Key 两种认证同步模式。
2. “快捷键”设置面板，支持为常用功能自定义全局快捷热键，包含按键录制、冲突检测与一键重置功能。
3. “存储”管理面板，可视化展示油猴脚本存储占用分布，支持分项查看缓存数据、一键复制、独立清理或重置出厂配置。
4. “更新日志”页面，内置各历史版本的演进记录与折叠卡片交互，直观展示每一次版本更新的具体细节。
5. “开发计划”页面，展示插件后续功能的演进路线与开发进展规划，并提供社区功能提议通道，共同见证插件成长。
6. “致谢”页面，向 [CF-Helper](https://chromewebstore.google.com/detail/codeforces-helper/ahoeafmlmoohkkalcickdnkifpfnolpj)、[CList](https://clist.by)、[OJ Better](https://github.com/beijixiaohu/OJBetter)、[Carrot-Plus](https://github.com/wuyuqian114514/carrot-plus) 等开源先驱与社区项目致敬。

**优化**
1. 优化了菜单的 UI 界面，提供了更为精细的子菜单分组。
2. 将原有的 LocalStorage 存储方式改为油猴脚本存储方式，避免可能超过 LocalStorage 潜在的 5MB 上限。
3. 在难度分“标签”展示样式下新增“表格内标签铺满单元格”选项，提供更轻柔色系的难度分单元格展示。
4. 为时间格式化模板字符串提供了更多格式字符串的支持和详细的内置文档介绍。
5. 为判题状态缩写提供了详细的内置速查文档。
6. 将队伍信息的相关展示逻辑，迁移到了 status 和 submissions 等页面。
7. 优化了更新日志的文档结构。

**修复**
1. 修复了 Codeforces 官方近期维护后导致读取的部分用户头像不可用的问题，增加了反代路径自动适配与加载失败自愈降级机制。
2. 修复了在题单页和比赛题单页第一列使用 Rating 列导致 [Competitive Companion](https://chromewebstore.google.com/detail/Competitive%20Companion/cjnmckjndlpiamhfimnnjmnckgghkjbl) 插件无法一键读取题单题目的问题。

### v1.5.1
`2026-08-24 01:39`

**新增**
1. 支持在设置面板中自由切换难度分呈现样式（经典“色块” / iView 风格“标签”）。
2. 支持在设置面板中通过开关控制难度分在不同区域（提交、状态、Hack、各大题单、榜单及题目页标签）的显示。
3. 支持开启并自定义时间格式化字符串，自带实时预览。
4. 支持在表格中显示用户头像，并在设置中支持自定义大小。
5. 支持在语言列显示语言专属图标（如 C++、Python、Go 等），并支持自定义图标大小。
6. 支持将判题状态进行极简缩写（如 `Accepted` -> `AC`, `Time limit exceeded` -> `TLE` 等）。

**修复**
1. 彻底删除了在普通页面题目链接旁附加 `[xxxx]` 分数文本显示的冗余逻辑。
2. 修复了关闭自定义时间格式时，表格时间列排版错乱的问题，完全恢复官方默认样式。
3. 修复了在使用深色背景插件（如 Dark Reader、CF-Better）时，难度分高亮背景刺眼的问题。
